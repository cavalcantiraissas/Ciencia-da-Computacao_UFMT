# Atividades de Classe - Programação em Java

Exercícios práticos realizados durante as aulas de Programação em Java, cobrindo orientação a objetos, herança, coleções, manipulação de arquivos e interfaces gráficas com Swing.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| `Calculadora.java` | Calculadora com operações básicas |
| `CalculadoraSimples.java` | Calculadora simples via terminal |
| `CalculadoraRaiz.java` | Cálculo de raiz quadrada com tratamento de entrada |
| `Contador.java` | Contador simples |
| `ConversorStringParaInt.java` | Conversão de `String` para `int` com tratamento de exceções |
| `DivisaoSegura.java` | Divisão com tratamento de exceção de divisão por zero |
| `Fibonacci.java` | Geração da sequência de Fibonacci |
| `ClasseEleitoral.java` | Verificação da classe eleitoral (voto facultativo/obrigatório) a partir da idade |
| `Carro.java` | Classe `Carro` com atributos e métodos básicos |
| `Livro.java` | Classe `Livro` com atributos e métodos básicos |
| `Main_Pessoa.java` | Herança: `Pessoa` e subclasse `Aluno` com uso de `super()` |
| `Main_Animal.java` | Herança e polimorfismo: `Animal` com subclasses `Cachorro` e `Gato` sobrescrevendo `emitirSom()` |
| `ContaBancariaDetalhada.java` | Simulação de conta bancária com histórico de operações |
| `CadastroPessoas.java` | Cadastro de pessoas em coleção |
| `ListaAlunos.java` | Gerenciamento de lista de alunos |
| `GerenciadorNumeros.java` | Operações sobre coleção de números |
| `GerenciadorPalavras.java` | Armazenamento de palavras únicas digitadas em um `HashSet<String>` |
| `LeitorArquivoTexto.java` | Leitura de arquivo texto |
| `GravadorArquivo.java` | Escrita de dados em arquivo |
| `AnalisadorArquivoSimples.java` | Uso da classe `File` para inspecionar existência, tipo, tamanho e caminho de um arquivo/diretório |
| `JanelaboasVindas.java` | `JFrame` com `JLabel` de boas-vindas e botão para fechar a janela |
| `JanelaLogin.java` | Tela de login com `JTextField`, `JPasswordField` e `JOptionPane` de boas-vindas |

## Como Compilar

```bash
javac NomeDoArquivo.java
java NomeDaClasse
```
