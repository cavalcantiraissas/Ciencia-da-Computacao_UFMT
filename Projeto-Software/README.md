## Trabalhos

Disciplina em andamento: os trabalhos serão adicionados ao longo do semestre.

## Conteúdo da disciplina

- Princípios de design: SOLID, DRY, KISS, YAGNI, coesão e acoplamento
- Padrões de projeto: criacionais, estruturais e comportamentais
- Estilos arquiteturais: camadas (MVC), arquitetura hexagonal e microsserviços
- Modelagem com UML e versionamento com Git e GitHub
- Metodologias ágeis: Scrum e Kanban
